# Estevez Guarda MVP 1

Objetivo desta wave: demonstrar valor operacional, não ampliar hardening.

Entregue:
- marca pública Estevez Guarda;
- Command Center com 3 operações demonstrativas;
- referências de documentos públicos;
- marcos por processo;
- Assistente Estevez ligado ao endpoint existente `/api/agent/chat`;
- prompts contextualizados por operação.

Para ativar o agente no Railway Backend:
`AGENT_ENABLED=true`
`AGENT_PROVIDER=openai`
`AGENT_MODEL=gpt-5.6-luna`
`OPENAI_API_KEY=<secret>`
`AGENT_STORE_CONTENT=false`

Nenhuma migration nova foi adicionada.
